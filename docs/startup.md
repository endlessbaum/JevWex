# 前回のモデルと設定を使う

一度「読み込む」が成功すると、そのモデル名と識別情報をブラウザに保存します。次回JevWexの判定ページを開いたときは、保存済みのモデルを、ハードウェア設定画面で保存した設定で自動的に読み込みます。拡張アイコンから開く画面は判定画面です。準備が終わると「判定する」が使えるようになります。判定そのものはボタンを押したときだけ実行します。

CPU/GPU、CPUスレッド数、GPUに任せる範囲、文章量の上限は既存の `jev.hardware.v1` を再利用します。設定を変更した場合は「設定を保存」または「モデルを再読み込みして適用」で保存してください。未保存の編集内容は次回へ持ち越しません。起動時のモデル記録は `jev.last-model.v1` です。

- 記録するのは最後に**読み込みが成功したモデル**です。別のモデルを選択・ダウンロードしただけの場合や、読み込み失敗では更新しません。
- 自動読み込みに使うのは拡張内の保存済みファイルだけです。モデルが消えていても自動再ダウンロードせず、モデル管理で追加するよう案内します。
- 端末から直接選んだGGUFはファイルそのものを保存しません。前回の名前と、同じファイルの再選択が必要なことを判定画面に表示します。
- 保存したGPUやスレッド設定が利用できない場合は、設定の見直しを案内します。設定を直せば通常の「読み込む」で再開できます。
- 起動時の確認が終わる前にモデルや設定を操作した場合は、その操作を優先して自動読み込みを行いません。
- ページを閉じれば推論ランタイムも終了します。常駐推論、外部API、新しい権限は追加していません。文章・画像・判定結果は今回の保存対象に含みません。

### 実行済み

型チェック、単体テスト93件、ビルド、既存UIの実Chrome拡張テスト7項目。

`npm run test:extension:resume`：Chrome for Testing 145.0.7632.6、実SmolLM2-135M-Instruct Q4_K_Mを使用し7項目成功。初回は公開配布先から取得し、再実行ではテスト用プロファイル内のキャッシュを再利用しました。

1. 成功したモデルの記録と、未読込モデルを選択しても記録を変えないこと。
2. ブラウザを終了・再起動後、オフラインでモデルとCPU2スレッド・context2048を自動復元し、実判定できること。
3. WebGPU設定を適用後にページを開き直し、GPU設定の復元と実GPU推論に成功すること。
4. 壊れたGGUFの読み込みが失敗しても前回の記録を保持すること。
5. 保存ファイルが見つからない場合の案内と、勝手に別モデルを使わないこと。
6. ローカルGGUFの使用名を保持し、再選択を案内すること。
7. 環境の論理コア数を超える保存設定で自動読み込みを停止し、設定修正後に手動で再開できること。

記録：[startup-test-results.json](startup-test-results.json)。推論・復元時のHTTP通信はありません。
